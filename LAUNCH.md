# Steroids Launch Checklist

## Repo hygiene

- [x] License
- [x] README with quickstart
- [x] Tests passing
- [x] Demo (`demo/skill-graph.html`, zero-dep, open in browser)

## What trending actually measures

GitHub trending ranks star velocity in a short window, per language. Spikes
come from distribution, not quality. No guarantees — most launches don't trend.

## Launch-day distribution

- Post in 3–5 dev communities where this fits (e.g. relevant subreddits like r/LocalLLaMA, harness Discords).
- Include a short demo gif of routing + the skill-graph demo link.
- Hacker News: one Show HN post, plain title, release notes in first comment.
- Cut a tagged release with concise notes (what it does, what it doesn't).

## Week-1 response plan

- Triage new issues within 24h; label bug / question / wontfix.
- Keep a running changelog; ship small fixes fast.
- Thank contributors by name; close the loop on every thread.
