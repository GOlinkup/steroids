# Steroids — Launch Pricing

Sell one clear outcome: Steroids helps people get more work done with AI agents, with less manual supervision.

Launch with the strongest working features, prove people want them, add the rest as they get built. Prices in USD — Steroids is open source and can reach users worldwide.

## Tiers

### Free — $0, for everyone

Promised free features: core skill routing, live agent lens, sessions/history, same-Wi-Fi phone access, LAN file transfer, remote access, phone approvals and notifications.

### Starter — $4/mo, for regular users

Saved workflows, persistent project memory, advanced routing settings, reusable task templates.

### Pro — $9/mo, for serious builders

Multi-agent orchestration, automatic retries, independent verification, project-aware task planning, skill creation tools.

### Power — $19/mo, for heavy workflows

Advanced parallel execution, overnight workflows, automatic recovery, benchmarking, cost optimization, deeper test automation.

### Team — $49/mo, for small teams

Shared project brain, team workflows, centralized policies, audit history, fleet administration.

## Billing approach

Charge for Steroids' software, not unlimited AI usage. Bring-your-own-model-key where practical — keeps inference costs from eating subscription revenue.

## Revenue math (before fees, tax, refunds)

| Plan | Example |
| --- | --- |
| 50 × $4 | $200/mo |
| 25 × $9 | $225/mo |
| 20 × $19 | $380/mo |
| 10 × $49 | $490/mo |

100 customers at $9/mo = $900 MRR before expenses. Getting the 100 is the hard part, not the pricing table. Comparable products charge ~$10–20/mo individual, so the range is plausible — but Steroids must demo value users can't get from tools they already have.

## Launch recommendation

1. Launch with Free + Pro at $9/mo first. One paid plan, not five.
2. Founding-member price of $4/mo for early supporters, stated clearly whether permanent.
3. Bring-your-own-model-key where practical.
4. Add $19 Power and $49 Team once users actually request those capabilities.
5. Measure return usage, task success, conversion to paid — not stars or downloads.

Before accepting payments: verify a payment processor supporting a South African business with international recurring payments (e.g. Stripe eligibility depends on location and setup).
