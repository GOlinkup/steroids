# Story S-V11-R2: Mirror + Reply as React (Sprint 2 re-draft)

Outcome: the React island (island-ui + island/bridge.py) carries the
Sprint 2 behaviors that survive the web: a self WebSocket relay with
reconnect-without-repairing, a durable offline outbox (exactly-once via
idempotency keys), and honest cost/permission UI. Phone-notification
mirroring does NOT survive: the web Notification API delivers local web
notifications only — it cannot read the phone's notification shade.
That scope cut is recorded here, not retried silently.

Task V11-R2-1: self WS relay browser↔bridge + reconnect (Kevin)
Description: browser WebSocket to the bridge's relay endpoint (pairing
  endpoint + key persist in localStorage; reconnects never re-pair).
  Backoff 1→30s clamp, want-up guard, status stream for UI + outbox
  flush hooks. s1 Python transport (drop_net) reused via bridge where
  the peer is a Python end; browser end speaks WS directly.
Do-not-touch: drop_net.py wire behavior (bridge exposes it, never forks it)
Acceptance:
- [ ] relay reconnects after network switch without re-pairing
- [ ] kill + restart resumes on persisted pairing (no fresh QR)
- [ ] cost stated honestly in UI (one socket + quiet state, no GMS claim)
Verification: loopback WS test; WiFi→hotspot switch without re-pair
Dependencies: bridge relay endpoint (new) + drop_net (exists)
Files likely touched: island/bridge.py (relay endpoint), island-ui/src/store.ts (RelayStatus), new relay hook
Size: M

Task V11-R2-2: offline outbox in React (Kevin)
Description: anything typed offline queues durably (localStorage JSON,
  FIFO) and fires in order on reconnect. Every frame carries a uuid-v4
  idempotency key; the far end dedups. Remove-after-confirm only.
  Direct port of the proven Flutter OutboxStore semantics.
Do-not-touch: send paths (queue wraps them, never rewrites them)
Acceptance:
- [ ] airplane-mode reply fires once, in order, on reconnect
- [ ] pending count visible, cancellable before fire
- [ ] flaky reconnect retries same key (far end sees it once)
- [ ] queue survives browser restart (localStorage)
Verification: toggle ×3 with log proof of single delivery; restart test
Dependencies: V11-R2-1
Files likely touched: new island-ui outbox module + tests
Size: S

Task V11-R2-3: Notification API scope note + permission UI (Kevin)
Description: record the cut — web Notification API = local notifications
  for island events (outbox fired, pairing approved) only; phone-shade
  mirroring stays a native/Android card (later app), never implied by
  the web UI. Permission prompt explains itself, denied path guides.
Do-not-touch: phone mirror (explicitly out of web scope)
Acceptance:
- [ ] scope note in spec + UI copy never promises phone mirroring
- [ ] denied notification permission shows guidance, not a dead screen
Verification: read-back of UI copy by human
Dependencies: V11-R2-2
Files likely touched: island-ui settings/notification copy (strings only)
Size: XS
