# Island spec (god-owed, unblocks Sprint 5)

## Identity
- One Steroids account (sign-up in Settings, Sprint 4). No golinkup identity, no shadow users table.
- Devices pair by certificate (Sprint 1 QR+PIN); device IDs live in the pair registry, never in a cloud directory.

## Profile (mirror-only)
- Fields: user_id, handle, avatar_url, bio, links[], verified, counts. Mirrored from linked accounts (Sprint 4 socials, gig profiles). Created where needed, never minted as a competing identity.
- Single source per field (grep-auditable). Unlink removes local tokens (Sprint 4 acceptance).

## Learn-me signals (on-device only, zero telemetry)
- Observed: app opens, music plays, task completions, briefing opens/skips, gig views/saves. Day-loop completions feed the evening card (Sprint 3).
- First-run: observe-only from install + max 3 skippable questions (Q8 default). Every learned datum viewable + deletable by the user (Sprint 5 acceptance).
- Suggestions: gigs → tasks → next steps, ranked by observed behavior after ~a week. No cloud analytics, no training on user data, no outbound without consent.

## Non-goals (v0.1.1)
- No cloud profile sync, no cross-user graph, no advertiser memory. Money split % stays a human business call.
