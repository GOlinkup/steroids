# Story S-V11-R4: Socials as React — link + reply (Sprint 4 re-draft)

Outcome: socials link fast via Settings in island-ui (OAuth on-device,
per-account link/unlink) and support read + reply only. Mastodon +
Bluesky first, Reddit next. X / IG / TikTok explicitly cut (paid or
no-reply-API — recon proved it, cut stands). All network calls live in
Python backend adapters; the browser never holds tokens.
